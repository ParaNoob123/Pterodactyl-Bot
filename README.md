# Ptero Bot – Easy Pterodactyl Control
Ptero Bot is a Discord bot that connects directly with your Pterodactyl panel, making server management simple and fast. With just a few slash commands, admins can:

👤 Create and assign panel users

🖥️ Deploy Minecraft servers instantly

⚡ Control resources (RAM, CPU, Disk, Backups)

📩 Send account and server details directly to users

Perfect for hosting communities, gaming networks, or anyone who wants quick Pterodactyl management without logging into the panel every time.
